# AI 侧边栏任务工作流设计

## 目标

在保留现有聊天、Tool Registry、浏览器控制队列、工具审计和权限边界的前提下，将 AI 侧边栏已有的页面分析、开发诊断和浏览器自动化能力组织为可见、可继续、可复用的任务工作流。

首期同时覆盖三类高频场景：

- 开发调试：页面状态、控制台、Network、源码和运行时诊断。
- 网页研究：标签页内容提取、搜索、截图和跨页面综合。
- 网页自动化：快照、填写、点击、等待和结果核验。

本设计不新增操作审批回放功能。现有高风险边界选择机制保持原样。

## 非目标

- 不替换普通聊天会话或强制所有消息进入任务。
- 不新增第二套工具执行引擎、权限模型或审计链路。
- 不将敏感上下文、完整聊天记录或不稳定页面定位符保存进技能。
- 不做团队共享、远程技能市场或自动触发技能。

## 任务层

### ChatTask

`ChatTask` 是附着于聊天会话的任务运行态。普通闲聊仍只产生消息；复杂请求可由用户显式发起或由系统建议转换为任务。

每个任务包含：

- 标题、目标和任务模板类型。
- 目标标签页和已选上下文引用。
- 计划步骤及其工具调用关联。
- 当前状态、开始/结束时间、错误摘要和可继续原因。
- 产物引用和可选技能草稿。

状态机固定为：

`preparing -> running -> waiting -> completed`

任务可从 `preparing`、`running` 或 `waiting` 进入 `failed` 或 `canceled`。工具、模型、网络、提取或调试器故障不会使会话失效；任务进入 `waiting` 或 `failed`，并保留可继续所需的上下文与错误原因。

### 任务模板

模板只提供初始指令、建议上下文、推荐工具组和产物格式，不直接执行工具，也不绕过既有 Tool Registry。

| 模板 | 建议上下文 | 推荐能力 | 默认产物 |
| --- | --- | --- | --- |
| 开发调试 | 页面状态、控制台、Network、源码、运行时 | Network、JS、Source Map、Runtime、截图 | 诊断报告、接口差异、复现步骤、类型草稿 |
| 网页研究 | 当前或多个标签页、提取正文、搜索结果、截图 | 页面提取、搜索、跨标签页浏览 | 结论、结构化摘录、对比表 |
| 网页自动化 | 页面快照、目标标签页、表单状态 | 快照、点击、填写、按键、等待、截图 | 自动化报告、结果截图、异常说明 |

### 侧栏表现

任务以消息流内的紧凑任务条目呈现，显示标题、目标标签页、状态、当前步骤、工具状态和取消/继续操作。普通消息保持原有阅读密度；任务细节按需展开，避免把工具菜单、设置或状态信息堆入主聊天界面。

## 上下文管理

### ContextItem

任务维护显式 `ContextItem` 清单，引用以下来源：

- 标签页及页面提取内容。
- 截图。
- Network 请求集。
- JS、Source Map 和运行时片段。
- 搜索结果和 MCP 工具结果。

每个条目记录来源、采集时间、脱敏状态、截断状态、摘要和引用次数。用户可固定、移除、刷新或压缩为摘要。

模型请求只注入当前任务选中的有效上下文。不同任务不得隐式共享上下文；聊天历史可作为语言连贯性来源，但不自动提升为工具上下文。

### 数据边界

沿用 Network、MCP 和浏览器工具的现有脱敏规则。上下文索引与产物默认保存摘要和引用，不复制 Cookie、Authorization、Token、Secret、密码或未脱敏响应体。

## 产物中心

### Artifact

`Artifact` 是任务完成或中间阶段的稳定输出，独立于具体聊天消息。首期类型包括：

- 结论
- 表格
- 代码片段
- 调试报告
- 自动化报告
- 截图

产物保留创建来源、所依赖的上下文引用、生成时间和文本/结构化内容。用户可继续围绕产物提问、复制或导出 Markdown。

开发调试模板可生成接口说明、请求差异报告、复现步骤和 TypeScript 类型草稿。产物只引用原始上下文，不将敏感原文作为导出默认内容。

## 技能

用户可将完成且验证过的任务显式保存为本地技能。技能由模板类型、用户可填写变量、所需上下文类别、推荐工具和预期产物格式组成。

技能不保存：

- 聊天全文。
- API Key、Token、Cookie、密码或其他敏感值。
- 未验证的页面元素 UID、选择器或临时快照。

首期只支持手动启动。启动时用户填写变量，系统检查所需工具与运行时可用性；不满足时解释原因，并允许退化为普通聊天任务。

## 集成与错误处理

- Tool Registry 是唯一工具发现和执行入口。
- 浏览器动作继续通过既有串行队列执行。
- 任务步骤通过工具调用 ID 关联审计摘要；不复制完整审计数据。
- 现有权限和边界选择继续生效，本设计不添加审批回放。
- 任何增强能力不可用时，主聊天可继续；任务呈现明确的降级原因与下一步建议。

## 验证

新增或扩展测试应覆盖：

- 任务状态转换、取消、失败和继续。
- 任务上下文选择、隔离、刷新和模型注入过滤。
- 产物创建、上下文引用、Markdown 导出与敏感字段排除。
- 技能变量校验、工具运行时不可用时的降级。
- 工具失败、模型失败、页面提取失败和 debugger 断开时的任务恢复。
- 三类模板各至少一条端到端闭环：开发调试、网页研究、网页自动化。

## 实施顺序

1. 引入任务与上下文的持久化模型及状态迁移测试。
2. 在聊天会话中接入任务条目与上下文清单。
3. 接入产物创建、展示和 Markdown 导出。
4. 实现手动保存和启动本地技能。
5. 补齐三类模板、降级路径和端到端验证。
